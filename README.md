# MathVault

A light maths reading library organised by **Form (F1–F6)** and **HKDSE topics**.

## Live site

- Home: https://tommy9866.github.io/Maths-note/
- Library: https://tommy9866.github.io/Maths-note/#/app

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:5173/Maths-note/

## Deploy

```bash
npm run deploy
```
