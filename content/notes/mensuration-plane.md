[[diagram:circle-area|Area uses the radius twice: π x r x r. Circumference is the distance around: 2 x π x r.]]

## Formula table

| Figure | Area | Perimeter |
|--------|------|-----------|
| Rectangle | length x width | 2 x (length + width) |
| Square | side x side | 4 x side |
| Triangle | (1/2) x base x height | sum of sides |
| Trapezium | (1/2) x (a + b) x height | sum of sides |
| Circle | π x r x r | 2 x π x r |

## Short ideas

- Rectangle: count unit squares → length x width.
- Triangle: two same triangles make a rectangle of area base x height.
- Circle: use π ≈ 3.14 if a decimal answer is needed.

## Number examples

| Figure | Data | Result |
|--------|------|--------|
| Rectangle | 8 by 5 | area 40, perimeter 26 |
| Triangle | base 10, height 6 | area 30 |
| Circle | r = 7 | area 49π, circumference 14π |
| Trapezium | a = 6, b = 10, height 4 | area 32 |
