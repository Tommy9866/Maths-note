## Formula / rule table

| Operation | Rule |
|-----------|------|
| Add / subtract | Line up decimal points |
| Multiply | d.p. in answer $=$ sum of d.p. in factors |
| Divide by a decimal | Move decimal in divisor and dividend the same amount |
| Mixed $\times,\div$ | Left to right (unless brackets say otherwise) |

## Derivation of the multiply rule

$2.43\times 1.5$ is the same as

$$\frac{243}{100}\times\frac{15}{10}=\frac{243\times 15}{1000}$$

So the answer has $2+1=3$ decimal places: $3.645$.

| Calculation | Result |
|-------------|--------|
| $82.5+7.64$ | $90.14$ |
| $53.1-2.48$ | $50.62$ |
| $2.43\times 1.5$ | $3.645$ |
