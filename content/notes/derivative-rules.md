## Basic rules

| Rule | Formula |
|------|---------|
| Power | $\frac{d}{dx}x^n = nx^{n-1}$ |
| Sum | $\frac{d}{dx}(f+g) = f' + g'$ |
| Product | $\frac{d}{dx}(fg) = f'g + fg'$ |
| Chain | $\frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x)$ |

## Common derivatives

- $\frac{d}{dx}\sin x = \cos x$
- $\frac{d}{dx}\cos x = -\sin x$
- $\frac{d}{dx}e^x = e^x$
- $\frac{d}{dx}\ln x = \frac{1}{x}$
