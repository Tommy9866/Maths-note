## Useful facts

| Fact | Formula (plain form) |
|------|----------------------|
| Product identity | LCM(a, b) x HCF(a, b) = a x b |
| Find LCM from HCF | LCM(a, b) = (a x b) / HCF(a, b) |
| Find HCF from LCM | HCF(a, b) = (a x b) / LCM(a, b) |

> This is a useful number fact. It is not a main junior exam theorem, but it helps a lot in calculations.

## Why it is true (simple idea)

When we write a and b with prime factors:

- HCF keeps the **smaller** powers
- LCM keeps the **larger** powers

Smaller power + larger power = all the powers in a x b.  
So HCF x LCM gives the same primes as a x b.

## Number examples

| a | b | HCF | LCM | Check |
|---|---|-----|-----|-------|
| 12 | 18 | 6 | 36 | 6 x 36 = 216 and 12 x 18 = 216 |
| 56 | 84 | 28 | 168 | 28 x 168 = 4704 and 56 x 84 = 4704 |
| 18 | 60 | 6 | 180 | 6 x 180 = 1080 and 18 x 60 = 1080 |

### Worked example

Find LCM(56, 84) if HCF(56, 84) = 28.

LCM(56, 84) = (56 x 84) / 28 = 4704 / 28 = **168**
