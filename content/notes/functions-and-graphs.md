## Formula / definition table

| Idea | Meaning / formula |
|------|-------------------|
| Function | each input $x$ maps to exactly one output $f(x)$ |
| Linear | $f(x)=mx+c$ |
| Quadratic | $f(x)=ax^2+bx+c$ |
| Reciprocal | $f(x)=\dfrac{k}{x}$ |
| Graph point | $(x,f(x))$ |

## Derivation / meaning

$f(2)=7$ means: when the input is $2$, the output is $7$. The graph is the set of all such points $(x,f(x))$.

## Number examples

If $f(x)=2x+1$:

| $x$ | $f(x)$ | Point |
|-----|--------|-------|
| $0$ | $1$ | $(0,1)$ |
| $2$ | $5$ | $(2,5)$ |
| $-1$ | $-1$ | $(-1,-1)$ |
