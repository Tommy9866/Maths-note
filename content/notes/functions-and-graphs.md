A function $f$ maps each input $x$ in the domain to exactly one output $f(x)$.

[[diagram:function-curve|Each x maps to one point (x, f(x)) on the graph]]

## Common forms

- Linear: $f(x) = mx + c$
- Quadratic: $f(x) = ax^2 + bx + c$
- Reciprocal: $f(x) = \frac{k}{x}$
