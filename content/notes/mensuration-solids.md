## Common formulas

| Solid | Volume | Notes |
|-------|--------|-------|
| Prism | $V = \text{base area} \times h$ | includes cuboid |
| Cylinder | $V = \pi r^2 h$ | |
| Pyramid | $V = \frac{1}{3} \times \text{base area} \times h$ | |
| Cone | $V = \frac{1}{3}\pi r^2 h$ | |
| Sphere | $V = \frac{4}{3}\pi r^3$ | surface $4\pi r^2$ |
