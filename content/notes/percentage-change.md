## Formula table

| Idea | Formula |
|------|---------|
| Percentage change | $\dfrac{\text{new}-\text{original}}{\text{original}}\times 100\%$ |
| Percentage increase | $\dfrac{\text{increase}}{\text{original}}\times 100\%$ |
| Percentage decrease | $\dfrac{\text{decrease}}{\text{original}}\times 100\%$ |
| New value after $+p\%$ | $\text{original}\times\left(1+\dfrac{p}{100}\right)$ |
| New value after $-p\%$ | $\text{original}\times\left(1-\dfrac{p}{100}\right)$ |

[[diagram:percentage-bar|Increase or decrease as a share of the original]]

## Derivation

Change relative to the starting value is

$$\frac{\text{new}-\text{original}}{\text{original}}$$

Multiply by $100\%$ to express it as a percentage.

## Number examples

| Situation | Working | Result |
|-----------|---------|--------|
| $80$ → $100$ | $\dfrac{100-80}{80}\times 100\%$ | $25\%$ increase |
| $50$ → $40$ | $\dfrac{40-50}{50}\times 100\%$ | $20\%$ decrease |
| $200$ up by $15\%$ | $200\times 1.15$ | $230$ |
| $90$ down by $10\%$ | $90\times 0.9$ | $81$ |
