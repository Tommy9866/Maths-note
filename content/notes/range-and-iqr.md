## Formula table

| Measure | Formula |
|---------|---------|
| Range | $\text{max}-\text{min}$ |
| Interquartile range (IQR) | $Q_3-Q_1$ |
| Median position (ordered data) | middle value(s) |

## Why IQR

Range uses the extreme values, so one outlier can make it huge.  
IQR uses only the middle $50\%$ of the data, so it is more resistant to outliers.

## Number examples

Ordered data: $2,3,5,7,8,10,12$

| Statistic | Value |
|-----------|-------|
| min | $2$ |
| $Q_1$ | $3$ |
| median $Q_2$ | $7$ |
| $Q_3$ | $10$ |
| max | $12$ |
| Range | $12-2=10$ |
| IQR | $10-3=7$ |
